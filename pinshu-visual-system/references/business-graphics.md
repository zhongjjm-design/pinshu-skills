# Business-graphic companion routing

The complete seven business-method cards now have one maintained home: the public pinshu-business-graphics companion. This core keeps the shared platform and delivery contracts. Install the complete repository bundle for all three visual Skills.

| Method | Relationship |
|---|---|
| typographic-metaphor | One memorable thesis expressed through type/object interaction |
| strategic-map | Positioning, competition and decision space |
| structural-section | Real layers, foundations and dependencies |
| editorial-collage | A deliberate image/document argument |
| engineering-blueprint-narrative | Components, interfaces, controls and exceptions |
| chinese-modernism | Chinese brand/cultural editorial argument |
| data-journalism | Trustworthy data, source notes and editable analytical charts |

Load the companion's SKILL.md, router and chosen mother card. If it is unavailable, report the missing full business workflow rather than reproducing its method from memory. The generic core can still plan registered illustration modes. Business method families are distinct from the twelve illustration modes; do not mix both visual grammars into one plan.
