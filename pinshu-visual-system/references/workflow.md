# Content to a visual set

1. Read the actual source, then state one main claim and its audience. Separate source facts from proposed metaphors.
2. Select an output: one illustration, cover, social card set or article illustration sequence. Choose the actual delivery platform.
3. Classify the information relationship: single-claim, process, comparison, hierarchy, components, true-loop or timeline. A feedback loop must have a real return path.
4. Select an available mode that can carry that relationship. Use atmosphere modes only for emotion, space or narrative; they do not explain mechanisms. Keep candidate experiments to one explicitly requested image.
5. Select one layout. The registry provides twelve basic compositions, three dedicated vertical compositions and three package sequences. Vertical output must use a real vertical reading path, not a stack of wide modules.
6. Lock one main scene/action or metaphor. Every object and connection must explain content. Check density and reserve a platform-safe title or anchor zone.
7. Compile the plan before rendering. For a sequence, compile each image separately and retain the shared palette/line/type language. Do not create style variety by cycling modes randomly.
8. Generate using the available image backend. Inspect the first image before continuing a set. Preserve each original and use new paths for revisions.
9. Inspect full-size images, thumbnails and the group side by side. Review the exported crop before calling the candidate ready.

A visual plan records intent and constraints. The agent supplies editorial judgment and actual image inspection. The scripts check declared contracts and file properties; they cannot determine aesthetic or semantic truth.

The special 3D mechanism-diorama method is reference-only in this public preview: use 3-5 physical modules and one actual relationship for mechanisms. It is not a default brand style. No public execution adapter for that method is bundled.
