# 定稿待发：正文、物料包与进度

2026-10-11 立，2026-10-12 修订（封面方向改由视觉出、加只查格式开关）。本约定由视觉 + 排版维护；写稿方要改格式，写进当期回流方案文件，由视觉方改。写稿维护者按本格式导出，不由视觉改写写稿 Skill。

## 明确选哪一篇

用户拍板后，唯一待发布正文为 `<workspace>/08_定稿待发/[账号]/日期_文章标题.md`，同目录有 `日期_文章标题·发布物料包.md`。`<workspace>` 是使用者自己选定的内容根目录，不要求发布者的知识库结构。Agent 每次读取这两个明确路径，核配对；不自动挑最新文件。`配图任务.json`、截图原图、配图及本地试排目录留在该篇过程文件夹，物料包提供路径。发布后的归档由用户决定，视觉/排版不代办。

正文第一行是 YAML 信息块。约定只用平铺字符串字段，值用双引号（按 JSON 转义也是合法 YAML），不使用嵌套、列表、别名或多行值。信息块后是一个 H1 和正文及来源。示例路径需换成当前文章真实路径：

```yaml
---
账号: "品叔"
定稿日期: "2026-10-11"
写手模型: "实际写手型号"
过程文件夹: "/绝对路径/日期_文章标题"
配图排版进度: "详见配对发布物料包的配图排版进度"
---
```

物料包也用平铺 YAML 信息块声明两项机器读取路径：

```yaml
---
正文路径: "/绝对路径/08_定稿待发/品叔/2026-10-11_文章标题.md"
配图任务路径: "/绝对路径/过程文件夹/配图任务.json"
---
```

物料包正文仍保留完整截图清单（出处、准确区域、放哪段后、说明什么、文字署名/权限状态）、标题/摘要/金句候选、事实待核与人工确认。封面方向不由写稿写（2026-10-12 改）：视觉 Skill 按标题和金句出 2 到 3 张真样张让作者挑，由主入口安排封面流程。Agent 根据这份清单维护同一份任务 JSON；不让用户填 JSON，不另建竞争清单。冲突时核原文和来源，更新任务后再跑。任务的 `source_md` 指向待发布正文，`article_sha256` 是包含 YAML 的原文件哈希；正文头不显示在发布正文中，原稿保持不变。只改变进度时更新物料包，不改正文头、不使正文任务哈希失效。

## 实际执行

Agent 读完物料包完整清单，核出处/区域/段落/作用与同一 JSON 逐项一致后，执行一次 `run_ready_article.py --article <正文> --kit <物料包> --bind-kit`。它只给任务记录物料包路径和内容指纹，排除整个“配图排版进度”小节；不宣称已理解或批准清单。正常运行先核这个绑定，需求改变则拒绝旧任务，Agent 核实并更新同一 JSON 后重新绑定。用户无需填 JSON。账号目录、日期前缀与待发布目录也须一致，不能用草稿伪装定稿。


```sh
python3 scripts/run_ready_article.py --article <明确待发布正文.md> \
  --kit <配对发布物料包.md> --output-dir <过程文件夹内新试排目录> \
  --space-id <本次已有ego空间编号>
```

没有浏览器时传 `--prepare-only`，不传 space-id。待截图时自动导出清单，不假装完成排版。入口核两份文件配对、任务哈希、过程目录及资产存放，复用原流水线。正式待发布模式直接按字节读取指定正文并分离 YAML，不依赖写稿导出器；明确核对输出等于信息块后的正文原字节。试稿模式才调用写稿 export_article.py，先核对编辑备注前字节，再分离头并更新派生导出回执。直接调用排版 `build.py` 也会分离开头 YAML。未闭合的信息块当场报错。H1、正文、来源与标点保留，不将元信息排出去。

每个阶段完成都回写物料包 `## 配图排版进度`：待截图、配图完成待排版、已试排待审、失败/阻塞分别写实际状态，带待办和预览绝对路径链接。自动入口覆盖的状态来自真实流程回执。仅完成中间步骤或独立审看登记后：

```sh
python3 scripts/run_ready_article.py --article <明确正文> --kit <配对物料包> \
  --record-progress "配图：已完成，手机审看待做；排版：待试排" --note "真实已完成步骤和待办"
```

需要附预览加 `--preview <预览.html>`，工具核它在本篇过程目录内，并有相邻的流水线/独立试排回执绑定当前正文、成图/任务及预览路径与文件哈希；失败/待截图回执不能挂成排版预览。只有文件存在不算本篇预览。在物料包进度小节的标记块内更新，其他人工说明保留；执行期间物料包改变则拒绝覆盖。确认过实际内容才写人工审看完成，不能把脚本状态用作审美判断。交付聊天中同时给可点击的绝对路径预览，并用宿主的打开文件能力展示预览。此入口不自动启动未读取技能的浏览器，不登录/上传/发文。

## 章节与表格

写稿无需为六章限制减步骤：排版允许任意数量 H2；经典版 01–06 仍用既有图片章号，07 起为文字章号，其他六款使用文字章号。未新增仿制章号资产。七至九步的实操稿可保持正常结构。七款工作页的目录名 `六款试排` 是兼容旧流程保留的路径名，不表示模板只有六款。

支持 2–4 列表格和提示词卡，超宽表格与会丢失内容的结构明确拒绝，不静默删、转图片或把事实改写成列表。代码块、原始 HTML、内嵌图片仍须另行审定，图片通过资产交接定位。
