# 外部画法通过同一入口使用

外部入口保留原作者和许可证。本包只提供依赖定位与交接，不复制第三方源码、模板、角色或参考图。

1. `select_styles.py`同屏返回适用内置模式与外部画法，并检查本机共享Skills目录的完整入口。可用`--skills-dir <本次实际Skills目录>`指定其他Agent安装目录。
2. 选中外部方向时执行`python3 scripts/select_styles.py --style <短名> --content-file <原文> --platform <平台> --structure <结构>`。物件照片改造另传`--source-image <用户允许使用的原图>`。输出是待执行交接，不是图片。
3. 读取输出中真实的`dependency_entry`全文，以及该依赖要求的具体风格卡。按源文和平台给出本次构图；商业用途、角色、素材权限和远程传输分别按上游与用户实际授权处理。
4. 执行可用工具，返回真实结果和实际调用信息。无可用生图工具时标待生图；缺包时给出对应Skill名称供安装，并继续不依赖该包的部分，不伪造外部画法成功。

怪诞与物件编辑固定无Gimi角色；橙线只借画法，商用按其许可；社交卡保留上游许可；实物涂鸦加载实际用户图片，不能拿参考图假冒用户物件。安装检查只验证入口存在，不宣称依赖执行或端到端兼容已经通过。
