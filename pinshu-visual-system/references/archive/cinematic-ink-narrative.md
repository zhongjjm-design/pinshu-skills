# Cinematic Ink Narrative

ID: `cinematic-ink-narrative`. Public status: `candidate`.

## Intent

Carry action, choice and cultural narrative through a cinematic ink scene.

## Visual grammar

One decisive action, ink texture, strong directional composition and useful negative space; restrained accents.

## Prompt skeleton

Create a {platform} image for {claim}. Use this visual grammar: One decisive action, ink texture, strong directional composition and useful negative space; restrained accents. Express only the source-supported scene or relationship. Preserve exact names and labels. Reserve whitespace for readable text.

## Acceptance

Inspect the rendered image at full size and thumbnail size. Check source meaning, exact text, single focal point, natural object/action relationships and platform crop. A registered mode does not establish acceptance of an individual image. Candidate modes require explicit single-image testing; frozen candidates remain blocked.
