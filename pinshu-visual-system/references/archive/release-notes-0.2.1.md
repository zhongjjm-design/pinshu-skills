# Visual repair candidate: core 0.2.1, companions 0.1.1

This maintenance candidate repairs independently reproduced planning and delivery defects. It does not add a Skill, a mode, or a generation backend.

- Numeric anchoring accepts numbers adjacent to Chinese text and comma thousands, while checking declared units/scales and rejecting unsupported values or bare-number excerpts. A declared verified dataset still requires factual review.
- Unknown top-level brief fields stop with diagnostics. The infographic quickstart uses `relations`; cross-package fields no longer silently disappear.
- Titles, unit labels, arrow verbs and exact labels all participate in conservative editable-text routing. Exact labels must occur in the source or have a real declared user approval; declarations do not establish truth.
- Export defaults to contain. Cover reports crop fractions. Delivery accepts only a reviewed final-platform PNG and verifies that packaging preserves those reviewed pixels.
- Editable plans require a hash-bound native-text SVG/PPTX and its final preview, copied together. File/native-label checks do not prove that the preview was honestly rendered from that file, that text is visibly legible, or that chart geometry is accurate; the reviewer must actually inspect those things.
- PNG provenance detection inspects metadata chunks rather than IDAT pixel bytes. Compressed metadata has bounded decoding and actionable format errors.
- Failed packaging writes a top-level FAIL report marking intermediates unapproved. Existing input files are retained.
- Infographic timelines remain unsupported by its three modes; the diagnostic names the business package's strategic-map timeline route.
- CI now installs pinned ImageMagick 7 and checksum-verified gitleaks, and fails if either is missing. The updated cloud workflow still requires a real run; YAML/shell parsing is not cloud execution.

Local checks include 17 core tests, 21 companion tests, 13 review regressions, 22 installer controls, release checks and three Skill-schema checks. A source-based Chinese four-layer infographic completed native SVG composition, final-size render, actual full-size/375px inspection, metadata-clean delivery and editable-source copying. A separate controlled 50-PNG cleaner test passed with zero pixel differences. These local tests do not establish image-model rendering quality, a five-image coherent design series, real colleague usability, or production-batch stability. The film self-test needs its separate dependency environment.

The old four example images are retained. Their thumbnail observations are now specific to each image. The origami cultural PASS is withdrawn pending owner/audience judgment; the two craft tests do not establish cross-theme layout variation. The historical business workflow illustration is not a substitute for the new requirement to review the final-platform export.

Human aesthetic acceptance and an independent post-repair review remain pending. Keep output status as a reviewed candidate until those steps are complete.
