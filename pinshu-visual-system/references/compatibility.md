# 兼容性范围

版本1.0.0-rc.2是已公开的试用候选，不是稳定版1.0。

- 本包脚本：Python3.10+，规划无第三方Python依赖；已做换目录隔离读取、25短名与6外部交接检查。
- 当前Codex：通过实际原生生图工具生成手帐横图与柔和体积竖图，完成平台导出和像素不变净化。它不证明其他Agent使用同一引擎。
- ZCode：候选包实际读取与选型测试单列记录；未把只读结果当生图通过。
- WorkBuddy：桌面独立任务已读取包、编译并生成1张后导出；图意/画法失败，不能宣称视觉一致性通过。
- Hermes：代码快照只读复核不等于Hermes生图或安装验收。

执行者先运行doctor确认Python、ImageMagick，再核本次会话真实可用的生图工具。没有生图工具就说明待生图；编译器和图像分析均不能代替生图。外部Skill未装则显示缺依赖，可选择适用内置画法，不假装已安装。

WorkBuddy单张实际测试：ImageGen生成和1600×900导出跑通，但两人共同折连续纸带被画成一双手拿折纸，且偏照片，图意/画法未通过；带AI生成水印。已强化完整媒介和参与/动作关系提示，未另花积分验证修复，因此不能宣称跨Agent审美一致性问题已解决。

本次实际请求比编译prompt少156字符；新增生图前全文连续性核对，对该真实样本拒绝。完整prompt通过仅证明提示词未丢失，不证明图意、画风或审美。

最新收尾：用户将WorkBuddy对话模型改成Hy3后，同内容单张复测已完成，工具回执中的完整prompt一致；两人和绘画感有改善，但源文制作说明被画成段落，仍失败。对话模型Hy3不是已确认的生图引擎，回执未给出图像模型。单次新增积分未有可信数值；界面累计5.71不当该次费用。

当前编译器已加入显式文字范围：源文/制作说明不作字幕，只有指定标题与标签可入画；精确排字层独立。修复后Codex原生单张出现两人和无字画面，未在WorkBuddy再次收费复测，因此其最新效果仍待验证。ZCode普通请求4分16秒无产物后停止，原因未核实；不是冷安装或生成通过。
