# Notebook Knowledge Explainer

ID: `notebook-knowledge-explainer`. Public status: `available-scoped`.

## Intent

Explain 3-5 actions as a clean working notebook page.

## Visual grammar

High-key warm paper, natural dark lines, pencil gray, sage and muted blue. Concrete objects, brief notes and one continuous reading path.

## Prompt skeleton

Create a {platform} image for {claim}. Use this visual grammar: High-key warm paper, natural dark lines, pencil gray, sage and muted blue. Concrete objects, brief notes and one continuous reading path. Express only the source-supported scene or relationship. Preserve exact names and labels. Reserve whitespace for readable text.

## Avoid

High-density tutorials; node count above five; floating sticker islands; card walls; unrelated metaphors.

## Acceptance

Inspect the rendered image at full size and thumbnail size. Check source meaning, exact text, single focal point, natural object/action relationships and platform crop. A registered mode does not establish acceptance of an individual image. Candidate modes require explicit single-image testing; frozen candidates remain blocked.
