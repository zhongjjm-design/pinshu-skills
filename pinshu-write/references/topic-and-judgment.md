# 选题与判断

第一个想法只是种子，不是结论。无论来自作者还是 Agent，都只看见局部，也带着常见盲区。不要把种子当金句，再堆材料证明它；资料的作用是让判断长大。

## 什么选题值得写

读者已经在问，或已经在意；文章至少给出下面一种价值：

| 读者感受 | 含义 |
|---|---|
| “说出了我说不清的话” | 共鸣，读者愿意转发 |
| “让我看见没看见的” | 读前相信 A，读后看见 B |
| “我能用” | 改变一个决定，或明天能采取一步 |
| “值得转给别人” | 让转发者显得有判断，或帮到同事客户 |

判断不必全网独创，但必须对读者有价值，并且是作者真正拥有的角度。主题可以撞，角度不能撞。不要用贪婪和恐惧拉读者。

## 选题卡

给作者 3 到 5 张卡，每张包含：

| 字段 | 内容 |
|---|---|
| 一句话选题 | 用读者自己的话写问题 |
| 来源 | 作者想法、业务现场、已有作品、资料库、读者正在读什么、读者提问 |
| 兴趣证据 | 为什么判断读者本周关心：热榜、阅读、收藏、评论或作者观察 |
| 价值 | 对应上面哪种读者价值 |
| 信念变化 | “读者原来以为 ___；读完发现 ___” |
| 缺口 | 现有讨论漏了什么；我们的暂定看法；哪里有分歧 |

## 资料包

每条资料写日期、来源、身份、支持什么、是否一手、是否高风险。厂商自述、个人经验、二手报道、研究报告、公开数据要分开标。材料不足时不要硬写，回到选题或缩小判断。

## 五步判断成熟

1. **种子判断**：作者或 Agent 的初始直觉。
2. **常识底线**：让多个模型或真实读者给主流回答；这些不能成为文章主贡献。
3. **扩展与拆分**：找事实、反例、利益相关方、条件和边界。
4. **反方审查**：写出最强反对意见和它成立的条件。
5. **成熟判断**：一句话说明主张、证据、边界和读者动作。

## 成熟度测试

成熟判断必须能回答：它比种子多了什么；反方最强点是什么；在哪些条件下不成立；读者读完先做什么；哪些事实还需核。答不上来，不进入大纲。
