# 提示词工具箱

复制提示词，填入尖括号内容，交给所选模型。默认要求简体中文回答；账号使用其他语言时再改。

## 1. 常识底线

用于基准判断阶段，交给两到三个不同供应商模型。

```text
请用简体中文回答，不要联网。
问题：<用读者自己的话写选题问题>
请给出今天一个见多识广的商业读者会给出的主流看法，5 到 8 点，保留通常建议。不要追求原创。最后列出你最不确定的两点。
```

## 2. 反方预演

用于判断确认前。

```text
请用简体中文回答。
这是我们准备发布的判断和关键证据：
<判断卡>
假设文章已经发布但失败了：读者认为它错、显而易见或没用。列出最可能的五个原因、最强反对意见，以及判断不成立的条件。不要缓和，不要替我改写判断。
```

## 3. 标题冷读

只给读者画像和标题，不给正文。结果只作参考，作者决定。

```text
请用简体中文回答。
你是<一句话读者画像>，正在手机上刷文章。
逐个判断下面标题：你以为它讲什么；是否想点开及原因；哪个词让你困惑。最后选出最想点开且看得懂的一个。
标题：
<编号标题列表>
```

## 4. 外行扫描

```text
请用简体中文回答。
你不是这个行业的人。读下面文章，标出所有让你停住的词、句子或段落；说明你卡在哪里。不要改写全文，只给问题清单。
<文章>
```

## 5. 结构审查

```text
请用简体中文回答，只看结构不改句子。
读下面文章后回答：一句话判断是什么；每个小标题是否推进同一判断；转折在哪里；结尾是否回答开头；哪些段落可删或位置不对。
<文章>
```

## 6. 事实抽取

```text
请用简体中文回答。
从文章中抽取所有事实性 claim，按“原句、需要来源的事实、当前来源、风险等级、是否需要作者复核”列成表。不要新增事实。
<文章>
```

## 7. 局部修订

用于只修一个部分，其他部分不能漂移。

```text
请只修改下面段落，目标是<目标>。不得改变文章判断、事实、标题和其他段落。输出：修改后段落；改动理由；是否引入新事实。
<段落>
```
