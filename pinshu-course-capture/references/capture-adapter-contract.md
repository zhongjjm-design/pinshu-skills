# Shared Video Transcript Capture Adapter Contract

This file defines the minimum result that every cloud-drive or video-platform adapter must return to the course-production workflow. It does not prescribe page selectors for each platform or treat one platform's interface labels as universal facts.

## Capture priority

1. Prefer transcript, subtitle, or transcription text already generated by the platform.
2. If the platform provides only an AI summary, mind map, or slides, do not treat them as a source transcript.
3. Use local ASR only when the platform permits download and the user has permission.
4. If no transcript exists, download is not authorized, or authentication cannot be restored, record a blocker and do not bypass permissions.

## Required adapter result

- `source_platform`: source platform.
- `source_type`: platform-native transcript, platform subtitle, or local ASR.
- `source_video`: video filename or identity displayed by the platform.
- `source_path`: a complete path, URL, or local file path that the user can verify.
- `text`: complete source text without buttons, player controls, recommendations, or AI summaries.
- `first_sentence`, `last_sentence`: opening and ending anchors.
- `extraction_method`: page text, exported file, copied text, or local transcription.
- `integrity_evidence`: identity plus opening, middle, and ending checks.
- `block_reason`: exact cause when capture fails.

## Handoff standard

The adapter's only responsibility is to obtain and prove the source text. Cleanup, STT correction, paired outputs, structured lectures, QA, and course promotion remain with the orchestrator and downstream Skills. Once saved, the source text is immutable and must never be overwritten by a generated artifact.
