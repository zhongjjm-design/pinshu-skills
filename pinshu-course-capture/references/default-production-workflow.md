# 默认生产流程

本文件说明公开候选的课程采集与生产顺序。它只描述文档合同，不声明程序已经执行通过。

## 语言策略

清单可以把 `output_language` 设为 `match-user`、`match-source` 或短 BCP-47 语言标签。旧清单缺失时，初始化记录 `match-user`。写作 worker 根据对话判断用户语言；无法判断时使用来源语言。CLI 只报告已存策略，不报告它自己猜出的语言。面向学习者的正文遵循该策略；稳定 ID、frontmatter key、枚举值和机器字段保留英文。

## 来源优先级

| 来源 | 状态 | 说明 |
|---|---|---|
| 平台原生逐字稿或字幕 | 首选 | 优先保存为不可变原始转写 |
| 平台转写、课程页文本、讲义附件 | 支持 | 可作佐证，不能替代原始转写 |
| 本地视频或音频 | 退路 | 只在用户明确授权且权限允许时转写 |

百度适配器按此顺序处理：先取网页播放器原生逐字稿、字幕或转写；只有用户明确授权可下载且权限允许时，才考虑本地转写。AI 摘要、思维导图和课件只能做辅助材料，不能替代来源逐字稿。不得绕过登录、验证码、付费或下载权限。

## 成功和阻塞

采集成功后，把原始转写保存到清单渲染出的来源路径，再把课次从 `DISCOVERED` 转为 `CAPTURED`。如果没有逐字稿、登录失效、文本明显截断，或用户没有下载权限且本地转写不可行，把课次标为 `BLOCKED` 并记录原因；只能继续不依赖该课来源的工作。

## 原始稿身份

Frontmatter 必须说明来源是平台原生逐字稿、本地 ASR 还是其他已批准来源。不得把平台 AI 摘要标成原始逐字稿。来源身份不清时，停在待核状态。
