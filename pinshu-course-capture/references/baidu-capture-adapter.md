# Baidu Netdisk Transcript Capture Adapter

This adapter reliably saves a transcript already generated by Baidu as an immutable source artifact. It does not clean, summarize, or generate paired outputs.

## Prerequisites

- The controlled browser is signed in to Baidu Netdisk.
- The course directory and complete video path are known.
- The runtime manifest contains the lesson number, official title, and video filename.
- Never bypass login, CAPTCHA, or payment blockers.

## Capture procedure

1. Open `https://pan.baidu.com/pfile/video?path=<encoded-complete-path>`.
2. Wait for the video resource and tab bar to stabilize.
3. In `.vp-tabs__header-item`, click the tab whose visible label means **Transcript**. In the Chinese interface, its two code points are `U+6587 U+7A3F`.
4. Wait for the transcript panel to stabilize; never extract while it is loading.
5. Start at the lecturer's opening text and stop before the playlist, file list, or player boundary.
6. Exclude buttons, timeline, playlist, recommendations, and other interface text.
7. Prefer page text nodes or the controlled browser's returned text. Use the clipboard only as transport, never as the sole source.
8. Save extracted character count, first sentence, last sentence, and source-video identity for the saved-file check.

## URL-encoding traps

Encode special characters in video filenames correctly:

- `+` -> `%2B`
- space -> `%20`

If the page shows only a Video tab and omits Notes, AI View, Slides, or Transcript, check path encoding and resource loading before concluding that no transcript exists.

## Integrity verification

All three evidence groups must pass.

### Identity

- Video filename, lesson number, and official title agree with the runtime manifest.
- The page is not showing stale content from the previous video.
- Different lessons never share one cached transcript.

### Saved-text equality

- Browser-extracted text and saved body are identical after newline normalization.
- The saved UTF-8 file can be read back.
- Frontmatter is excluded from body-length counts.

### Content completeness

- The opening, middle, and ending contain source text.
- First and last sentences are complete.
- The ending is not a fragment or obvious loading cutoff.
- No large duplicate section, mixed lesson, or interface contamination is present.

A natural sign-off is not mandatory; a lecturer may not say goodbye. When there is no sign-off, use final-sentence completeness, video duration, and the end of the transcript panel together.

## Save target

Save under the course root at the source path rendered from the manifest.

Frontmatter contains at least:

```yaml
---
course_id: <course identifier>
lecturer: <lecturer>
lesson_no: <lesson number>
original_title: <official title>
source: Baidu Netdisk video transcript
source_video: <filename>
source_path: <complete path>
extraction_status: captured
---
```

Preserve the Baidu transcript body exactly. Do not clean it, correct STT, or remove repetition.

## Blockers and retry

- Not signed in or CAPTCHA: `BLOCKED`; ask the user to restore access.
- Transcript tab absent: navigate once more, check encoding, and start playback to trigger loading. If it is still absent, record that the platform did not generate a transcript.
- Empty or apparently truncated transcript: retry for a bounded interval; if still defective, block that lesson.
- A blocked lesson must never be skipped silently, but it need not stop unrelated lessons.
- Mark `SKIPPED` only when the user or a reliable course source confirms that the lesson requires no processing.
