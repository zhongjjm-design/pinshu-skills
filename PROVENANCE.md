# Provenance

## Maintained public work

Aidan (Pinshu) is the named creator and maintainer of this public Skill suite. The repository's Git history records public-repository commits and is the authority for changes made within that repository from those commits onward.

Repository history and provenance of files that existed outside the repository are different evidence sets. A repository commit can prove what entered the repository at that commit; it cannot by itself identify who created or changed an earlier globally installed file before import.

## Known provenance gap

On 2026-10-06 and 2026-10-07, an external synchronization affected globally installed course-skill files. The synchronization could not be attributed to a specific author, and those installed files had no file-level Git history at that time. This document does not guess an author, tool, or intent for that event.

The public repository now provides file-level Git history for repository work. That history must not be retroactively presented as proof of authorship for the earlier global-installation state.

## Evidence policy

- Attribute repository changes from Git commits and reviewed release records.
- Attribute pre-repository material only when a verifiable source record exists.
- Label unknown authorship as unknown rather than inferring it from file timestamps, current ownership, or later commits.
- Keep local course data, private paths, credentials, and project-specific dictionaries outside the public repository.
